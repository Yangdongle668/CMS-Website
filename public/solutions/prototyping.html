The Pilot Line

A dedicated line for low-MOQ runs.

Our Dongguan pilot line runs the same winding, stacking and sealing equipment as the MP line — but configured for 100–5,000 pcs batches. Process parameters transfer cleanly into mass production.

A-sample: feasibility (2 weeks)

First functional cell built with soft tooling. Confirms geometry fit, capacity, voltage curve and basic safety. Quantities: 10–50 pcs.

B-sample: integration (3–4 weeks)

Hard-tooled cell with correct connector, BMS and label. Enough units for you to run enclosure tests, EMI scans and drop/shock.

C-sample: pre-production (4–6 weeks)

MP-equivalent cell. Submitted for UN 38.3 and IEC 62133. Statistically valid sample size for process capability studies.
