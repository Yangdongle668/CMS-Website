# 手机、平板、电脑适配

网站沿用现有设计和品牌配色，统一处理前台内容和后台管理的响应式布局。

## 布局行为

- 手机：卡片单列，按钮不超出所在容器，表单字段单列，输入字号适合触摸输入。首页采用紧凑图文布局：文案、小型产品图、操作按钮依次排列，不再以大图占满整屏；短屏可自然滚动。
- 平板：卡片按可用宽度变为一列或两列；触屏设备提供菜单入口。后台窄屏侧栏改为抽屉，纵向滚动浏览全部导航。
- 电脑：保留多列布局、完整导航和后台侧栏。统计图表和内容区使用可收缩的网格列。
- 文章、规格、后台数据表：在独立区域内横向滚动，可用键盘聚焦，不撑宽整页。
- 菜单：支持关闭按钮、背景点击、Escape、焦点回到触发按钮、菜单内部 Tab 循环及跨断点恢复页面滚动。
- 后台：产品、文章、页面、支柱页编辑表单及各选项卡，访客统计、SEO、robots、漏斗筛选器都纳入检查。

## 可重复验证

```sh
# PostgreSQL 连接变量与 npm test 相同；此云环境可以先加载已准备的配置。
source /workspace/cms-environment/dev-env.sh
npm run build
npm run responsive:check
npm test
npm run lint
```

`responsive:check` 使用本机 Chromium 与临时种子数据库，不更改现有管理员账号或业务内容。可通过 `CHROME_PATH` 指定浏览器。它检查页面实际宽度、裁切、导航操作以及设置/编辑器选项卡，并将 JSON 结果和代表截图保存至被忽略的 `.visual/responsive/`。

默认覆盖 320、375、480、640、768、820、1024、1280、1440、1920px。支持单独检查页面、小高度窗口和触屏：

```sh
npm run responsive:check -- --page /,/contact.html --widths 667,844 --height 390
npm run responsive:check -- --page / --widths 1366 --height 1024 --touch true
```

检查不以隐藏横向溢出代替修复：除明确标记为 `aria-hidden` 的反垃圾陷阱字段外，可见内容仍按实际容器边界检查；允许用户滚动的表格和热力图单独处理。当前验证使用 Chromium 渲染与触摸模拟，不代表已经做过 Safari 或 Firefox 真机验收。
